# Professional Profile

## My role
I work as a front-end developer in an online-banking web team. I build and
maintain customer-facing React components against our internal design system.

## My expertise
My main areas of expertise are:
- React and TypeScript component development
- Design-system and component-library work (tokens, theming, reusable components)
- Web accessibility (WCAG 2.2 AA, EN 301 549) and inclusive UX
- Front-end performance and automated testing (Jest, Playwright)

## My current goals
At the moment, I want to:
- ship the redesigned payment flow as accessible, reusable components
- raise our accessibility and Lighthouse scores on key journeys
- use MCP to speed up my own development and documentation workflow

## How an AI assistant can help me
An AI assistant can help me with:
- summarising refinement and design-review meetings
- drafting component documentation and usage examples
- scaffolding unit and end-to-end tests
- organising my learning notes
