# Refinement Summary Prompt

Use the available knowledge bank context to summarise my refinement or
design-review notes.

The summary should include:

1. Components or screens discussed
2. Design and accessibility decisions made
3. Open questions and blockers
4. Action items, with an owner where mentioned
5. Suggested next steps for the front-end work

Write the output in a professional and concise style, and flag anything that
affects accessibility explicitly.
